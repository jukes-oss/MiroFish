# 分层抽样与行为先验 v1

这些配比是产品的**可审计场景假设**，没有代表中文 X 人口的统计依据；禁止称为真实用户分布。默认 120 个虚构账号、3 个曝光波次，每账号仅曝光一次；最大 240 个、4 波。人数不是 LLM 调用次数，波次不是让全部账号重复发言。24 人只用于开发冒烟，不能支撑默认质量验收。

## 不可变槽位

主圈层互斥，仅用于分配配额；账号可有多个次兴趣。身份、地域、立场、关系、风格是独立维度，不能把某地域或性别绑定某立场。

另行分配边际配额（均独立、总和 120）：

- `relation`：`fan=18, stranger=90, detractor=12`。粉丝也可能反对，黑粉也可能无动作。
- `activity`：`low=84, medium=30, high=6`。活跃指习惯，不是强制执行动作。
- `language_style`：`zh_hans_casual=42, zh_hans_formal=18, zh_hant=24, mixed_zh_en=24, terse_slang=12`。
- `reach`：`ordinary=108, kol=8, institutional=4`。与主圈层交叉；KOL 不自动获得点赞。
- `predisposition`：`receptive=24, skeptical=24, ambivalent=24, disengaged=48`。这是对新观点的先验态度，不是对草稿的最终 stance。
- `region_context`：`mainland=42, hong_kong=12, taiwan=18, overseas=36, unspecified=12`。不推断真人所在地。
- 每槽位固定 `agent_id, primary_group, secondary_interests, relation, activity, language_style, reach, predisposition, region_context, value_priorities, disagreement_topic`。`value_priorities` 从隐私、效率、平等、自由、稳定、证据、收益、幽默等标签中抽取 2 个；分歧主题不是强制反对当前草稿。

算法：按主圈层比例用最大余数法分配整数，余数相同按固定枚举顺序。对其他维度分别按配额用独立 RNG 子种子洗牌，再用受限交换避免人为捆绑（有至少 4 人的圈层覆盖至少两种关系或态度；极小开发样本不保证全覆盖）。记录失败约束，不偷偷改配额。禁止对 8 个维度做全笛卡尔积。用户选择特定受众时创建新版本配额，仍须总和与边际校验；报告显示采用哪一版。

`disengaged` 不等于行动 `none`，`skeptical` 不等于已表达反对。最终 stance 只能从有效动作记录获得。性别可不指定；圈层角色不作为攻击性、智力或道德的代称。所有显示名加「虚构」标记，禁止仿冒真实账号。机器人只模拟重复、空泛或推广倾向，不执行真实灌水。

## 默认动作先验：先抽候选，再允许放弃

| candidate_action | 每次曝光先验 |
| --- | ---: |
| none | 90% |
| like | 7% |
| reply | 1.5% |
| repost | 0.8% |
| quote | 0.7% |

这是**候选动作的工程先验**，不是 X 实测比例，也不是实际动作保证。程序按 seed 独立多项分布抽样；不是每轮硬凑条数。`none` 直接记录规则划走，无 LLM 调用。其他候选只允许 `{candidate_action, none}`，LLM 判断该账号是否值得执行，允许放弃。执行率因此可能低于表中比例。这样不会靠一句“多数人沉默”来约束模型，也不会把所有人都叫来评论。

在候选分配前，可按版本化 `activity` 乘数 `low=0.7, medium=1.5, high=2.7` 调整非 none 的总概率（默认加权均值为 1），各非 none 类型间比例不变，none 补足至 1。单账号非 none 概率上限 0.3；更改配额后重新归一化并记录实际均值。与立场无关，不能优先叫醒反对者。初版不加入“争议越大叫醒越多人”的模型调度，避免循环自证。

默认 120 次曝光约 12 次行动请求，约 2 次回复候选；可能为零，允许 top_replies 为空。该方法约束了互动上界，不能表达真实爆款的指数传播；必须与“只抽先验、不看文本”的基线比较。若无法证明文本带来增益，只对外提供风险与改写备忘，不声称预测力。

冷热缓存不改变统计：固定槽位与人设缓存可跨同一受众配置的草稿复用（不包含草稿）；同一运行事件不得复用不同 seed 的结果。评估重复运行关闭动作和报告结果缓存，但允许固定人设缓存。
